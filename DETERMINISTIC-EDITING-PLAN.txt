DETERMINISTIC EDITING EXPANSION — 2026-09-21

Authorized design: conversation proposes one operation, deterministic renderer executes,
Jev classifies only. A single capability registry describes arguments, selection,
reference requirements, preservation scope, and examples. Never advertise unsupported
automation or use a generation fallback for a deterministic operation.

1. Registry + conservative parameter parsers + Jev criteria and confirmation cards.
2. Verified local pixel tools: tracked blur/pixelation, exposure/contrast,
   supplied text/captions, logo overlay, four-corner planar replacement.
3. Timeline and delivery: keep/remove range, move range, frame-repeat speed,
   freeze, split metadata, crop/resize, export, audio fades. Preserve revision
   metadata and restore it on undo; previews use candidate dimensions/duration.
4. Tests: masks/gaps/outside-scope pixels, real encode, geometry/metadata/undo,
   parsing ambiguity and ownership, conversation execution.
5. Browser acceptance: chat -> confirmation -> preview -> apply -> undo.

Constraints: source masters are 30fps, <=1080p, <=60s. Segmentation is not ground
truth. Planar overlays require ordered convex corners and reviewed tracking.
Text is supplied, not auto-transcribed. Speed uses existing frames, not invented
slow-motion frames. Audio filters re-encode audio; video-only effects copy audio.
Generation cannot guarantee semantic correctness; deterministic scope cannot expand.

Automation next: automatic selection proposals with uncertainty, not silent guesses.
Implemented status must be based on tests and app verification, never registry presence.

CURRENT LIMITS / AUTOMATION ROADMAP
- Jev chooses a tool; it cannot provide executable code or bypass validated bounds.
  New live Jev accuracy has not been measured. Exact commands work without a call.
- Semantic object selection remains a reviewed mask. Future automatic proposals
  must expose uncertainty, respect occlusion and stop at uncertain tracking gaps.
- Planar replacement needs four ordered tracked corners, not a SAM silhouette.
  A flat image overlay does not solve arbitrary object deformation or occlusion.
- Supplied text is a fixed caption/title, not speech transcription. Logos use a
  fixed top-right position. Crop is centered; resize letterboxes the whole clip.
- Split stores a clip boundary; reorder moves the selected interval to start/end.
- Speed repeats/drops existing frames and adjusts audio. Freeze holds the first
  selected picture while retaining audio. No synthetic smooth slow motion.
- Automatic multi-step editing and removing review are future work. This release
  retains confirmation and preview before changes become the current revision.
